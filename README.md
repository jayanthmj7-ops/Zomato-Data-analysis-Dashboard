Zomato is one of India's leading food delivery and restaurant discovery platforms. 
**This project analyzes restaurant-level data to uncover insights around:**
**Restaurant distribution by city/locality
Ratings and customer rating trends
Pricing patterns (cost for two)
Online delivery vs. dine-in availability
Popular cuisines
Restaurant opening trends over time**
The same dataset was analyzed using four tools to compare workflows, visualization capabilities, and querying approaches.

🛠️ Tools & Technologies

Tool and Purposes
Microsoft Excel - Data cleaning, PivotTables, PivotCharts, and a summary dashboard.
MySQL - Data storage, structured querying, and analytical SQL queries.
Tableau - Interactive, visual dashboard for exploratory analysis.
Power BI - Business-style interactive dashboard with DAX measures and KPIs.

🔑 Key Insights

Identify which cities have the highest concentration of restaurants
Determine top-rated cuisines and price segments
Understand the relationship between online delivery availability and ratings
Track restaurant growth trends over the years
